# 🍽️ En el restaurante- comida y bebida 

## 📝Descripción

Este recurso consiste en una guía completa diseñada para que el estudiante de nivel A2 se desenvuelva con confianza en un restaurante árabe. Incluye una cantidad variada de platos y bebidas tradicionales. vocabulario sobre utensilios, expresiones de cortesía, jergas dialectales y una introducción sobre normas alimentarias como (Halal/Haram).

## 📊Nivel 
A2

## Tiempo estimado
40 minutos

## 🎯Objetivos

1.💡**Aprender** el vocabulario de los platos y bebidas míticos del árabe.
2.✍️**Practicar** la interacción social en un restaurante a través de diálogos realistas.
3.🚀**Desarrollar** la capacidad para identificar restricciones alimentariasy dietas especiales en árabe.

## Competencias
1.🗣️**Expresión oral** uso de expresiones para pedir comida, preguntar precios y saludar cortésmente. 
2.📖**Comprensión escrita** lectura de menús, ingredientes y descripción de platos típicos.
3.🌍**Competencias interculturales** comprensión de leyes sobre la comida como Halal y diferencias dialectales gastronómicas. 

## Herramientas usadas
-⌨️ Markdown

## 📚Contenido
1.🔤**Vocabulario**
-Platos principales
-Bebidas calientes y frías
utensilios de mesa

2.📏**Gramática**
-Uso de particulas interrogativas para pedidos
-Estructura de frases para expresar deseos
3.💬**Expresiones útiles**
-Fórmulas de cortesía 
-Jergas regionales.

## 💡Cómo usarlo
Está diseñado para una inmersión gradual. Se recomienda primero revisar la sección de platos y bebidas y después estudiar el vocabulario de utensilios y expresiones de cortesía. Se practica finalmente con un ejemplo y se realiza para consolidar lo aprendido.
