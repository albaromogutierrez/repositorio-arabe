📘 Teoría: La Presentación Personal en Árabe (A1-A2)

La presentación personal en el mundo árabe no es un mero intercambio de datos, sino un acto social que establece el nivel de respeto, hospitalidad y cercanía entre los hablantes.

1. El Protocolo del Saludo

Toda presentación debe seguir un orden ritual de saludo y respuesta:

  • As-salamu alaykum: Es la fórmula universal y más educada (“La paz sea contigo”).
  • Wa alaykum as-salam: Es la respuesta obligatoria (“Y con vosotros la paz”).
  • Ahlan wa sahlan: Se utiliza en contextos más relajados para dar la bienvenida o saludar de forma cercana.

2. Identidad y Pertenencia

Para presentarse se utilizan estructuras nominales (Sujeto + Predicado) sin necesidad de usar el verbo “ser” en presente:

  • El Nombre: Se utiliza el sustantivo Ism (nombre) unido al sufijo posesivo de primera persona -i (mi), resultando en Ismi…
  • El Pronombre Personal: Se emplea Ana (Yo) como base para la mayoría de las descripciones personales.
  • Nacionalidad: Se expresa mediante la preposición min (de) seguida del país, o mediante el adjetivo gentilicio.
  • Regla de Género: Para formar el gentilicio masculino se añade una -i (ī) al final; para el femenino, se añade -ia (iyya).

3. Edad y Ocupación

  • La Edad: Se comunica como una posesión del tiempo vivido mediante la palabra Umri (mi edad) seguida del número y el término sana (año).
  • Acciones Diarias: En el nivel A2 se incorporan verbos en presente para definir la ocupación, como Adrus (estudio) o A’mal (trabajo).
  • Sustantivos Profesionales: Se usan términos como Talib (estudiante), Mu’allim (profesor) o Muhandis (ingeniero) para definir el rol social.

4. Expresión de Gustos y Carácter

Para personalizar la comunicación, se introducen preferencias y rasgos de personalidad:

  • Preferencias: Se utiliza el verbo Uhibbu (me gusta/amo) o su forma negativa La uhibbu (no me gusta).
  • Temas de conversación: Áreas comunes incluyen Al-qira’a (lectura), Ar-riyada (deporte) y Al-musiqa (música).
  • Descripción psicológica: Se añaden adjetivos como Latif/a (amable) o Mujtahid (trabajador) para enriquecer la descripción.

5. Fórmulas de Cierre (Etiqueta y Adab)

La cultura árabe valora profundamente el cierre cortés de una interacción:

  • Tasharrafna: Es la expresión estándar para indicar “encantado” o “es un honor conocerte”.
  • Fursa sa’ida: Significa literalmente “ocasión feliz”, equivalente a “un placer”.
